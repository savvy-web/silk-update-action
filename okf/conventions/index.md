# Convention

* [Adopting a service into a second consumer is a layer-wiring change](adopting-a-service-is-a-wiring-change.md) - When a second domain layer starts resolving a service in its layer body, provide that service to it in `makeAppLayer` in the same change — Action.run accepts an unprovided requirement silently, so nothing else will catch the omission.
* [Annotate every schema reused in more than one place with an explicit identifier](annotate-shared-schemas.md) - A Schema.Struct or Schema.Literals value referenced from two or more places in the result-output schema must carry an explicit `identifier` annotation, or the JSON Schema generator invents a positional name for it.
* [Code style — extensions, tabs, no barrels, conventional commits](code-style.md) - Relative TS imports carry an explicit .js extension; Node built-ins use the node: protocol; type-only imports use `import type`; formatting is tabs, enforced by Biome; commits are conventional format with DCO signoff and no markdown in the body; no barrel re-exports anywhere.
* [Declare a service's layer as a static field inside the class body](static-layer-in-class-body.md) - Every domain service exposes its layer as `static readonly layer`, declared inside the class body rather than assigned after it, and resolves its own dependencies inside that layer so each member's requirement channel is never.
* [Demonstrate a failure path with a test, or leave it out of the signature](no-export-without-construction-site.md) - A type-level construct — an error union member, a service tag, an interface field — that no code in src/ ever constructs, resolves, or reads is a claim the type system carries indefinitely and no test can falsify; delete it rather than keep it "for completeness".
* [Mirror src/ under __test__/unit/ and keep helpers out of reserved directories](test-layout.md) - Every unit suite lives under __test__/unit/ mirroring src/, never co-located; utils/, fixtures/ and snapshots/ are reserved for non-test helpers at any depth, enforced by this repo's own guard rather than the runner.
* [Never rewrite the dev branch — commit, don't squash, rebase, or force-push](never-rewrite-dev.md) - dev is the long-lived feature branch. Commit ordinary commits directly to it; never squash, rebase, or force-push it, because a consumer pinning `@dev` runs the committed dist and that consumer's CI is pinned to whatever dev currently is.
* [Read every input through ActionInput, never bare Config](read-inputs-via-actioninput.md) - readInputs must resolve every action input via ActionInput.*, not Config.*, because bare Config resolves nothing under the runner's mangled INPUT_* names and silently takes its default.
* [Require the workspace root as a parameter everywhere it is used](workspace-root-is-required.md) - Every service method and standalone helper that reads or writes workspace files takes the workspace root as a required parameter; none may default to process.cwd().
* [State what would falsify a load-bearing claim, or say it is unverified](write-falsifiable-claims.md) - Every load-bearing claim in documentation, a comment, or a commit message must name what would change the answer, or say plainly that it is unverified. Re-derive counts and enumerations by command rather than editing a stale number, and check a doc against itself before checking it against the code.
